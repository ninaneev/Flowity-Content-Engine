# Supabase — SQL para slides editáveis em todos os posts

Este script cria uma tabela para guardar o texto e a ordem dos slides de cada publicação, preenche slides iniciais para os posts existentes e prepara slides para novos posts.

> Antes de executar: confirme que o projeto Supabase tem `public.posts` com `id`, `hook`, `body` e `cta`, conforme o modelo do Flowity. Faça backup do banco antes de aplicar em produção.

## 1. SQL da migration

Cole o script no **Supabase → SQL Editor** e execute:

```sql
begin;

create table if not exists public.carousel_slides (
  id bigint generated by default as identity primary key,
  post_id integer not null references public.posts(id) on delete cascade,
  position integer not null check (position between 1 and 10),
  slide_text varchar(220) not null check (length(trim(slide_text)) > 0),
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now(),
  constraint carousel_slides_post_position_unique unique (post_id, position)
);

create index if not exists idx_carousel_slides_post_position
  on public.carousel_slides (post_id, position);

create or replace function public.touch_carousel_slide_updated_at()
returns trigger
language plpgsql
as $$
begin
  new.updated_at := now();
  return new;
end;
$$;

drop trigger if exists trg_carousel_slides_updated_at on public.carousel_slides;
create trigger trg_carousel_slides_updated_at
before update on public.carousel_slides
for each row execute function public.touch_carousel_slide_updated_at();

create or replace function public.sync_initial_carousel_slides(p_post_id integer)
returns void
language plpgsql
as $$
declare
  v_post public.posts%rowtype;
begin
  select * into v_post
  from public.posts
  where id = p_post_id;

  if not found then
    return;
  end if;

  insert into public.carousel_slides (post_id, position, slide_text)
  values
    (v_post.id, 1, left(coalesce(nullif(trim(v_post.hook), ''), 'Título do carrossel'), 220)),
    (v_post.id, 2, left(coalesce(nullif(trim(v_post.body), ''), 'Adicione o conteúdo deste slide.'), 220)),
    (v_post.id, 3, left(coalesce(nullif(trim(v_post.cta), ''), 'Qual é a sua opinião?'), 220))
  on conflict (post_id, position) do nothing;
end;
$$;

-- Preenche os posts já existentes sem sobrescrever slides que já foram editados.
do $$
declare
  v_post_id integer;
begin
  for v_post_id in select id from public.posts order by id loop
    perform public.sync_initial_carousel_slides(v_post_id);
  end loop;
end;
$$;

-- Inicializa os slides quando um novo post é criado.
create or replace function public.create_initial_carousel_slides_trigger()
returns trigger
language plpgsql
as $$
begin
  perform public.sync_initial_carousel_slides(new.id);
  return new;
end;
$$;

drop trigger if exists trg_posts_create_carousel_slides on public.posts;
create trigger trg_posts_create_carousel_slides
after insert on public.posts
for each row execute function public.create_initial_carousel_slides_trigger();

commit;
```

## 2. Conferir o resultado

```sql
select p.id as post_id,
       p.hook,
       count(s.id) as total_slides,
       string_agg(s.slide_text, E'\\n---\\n' order by s.position) as textos
from public.posts p
left join public.carousel_slides s on s.post_id = p.id
group by p.id, p.hook
order by p.id;
```

Cada post deverá ter pelo menos 3 slides iniciais. O script não substitui texto já salvo para a mesma posição.

## 3. Exemplo de edição

```sql
update public.carousel_slides
set slide_text = 'Texto atualizado para este slide'
where post_id = 4 and position = 2;
```

Troque `4` pelo ID real do post.

## 4. Segurança

Não habilite acesso público irrestrito à tabela. Se o frontend acessar o Supabase diretamente, habilite RLS e crie políticas que limitem leitura e gravação aos posts que o usuário tem permissão para editar. Se o acesso for feito pelo backend, valide autenticação e autorização no backend e mantenha a chave `service_role` fora do navegador.

## Importante sobre a integração

Esta migration cria e popula o armazenamento no Supabase. Para que o editor carregue as alterações salvas após atualizar a página, o frontend/backend também precisa ler e gravar `public.carousel_slides`. O guia de integração em `docs/integracao-frontend-slides-editaveis.md` descreve esse contrato. Não considere a tabela integrada à interface apenas por executar o SQL.
